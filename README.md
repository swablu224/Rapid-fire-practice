
This is a script to practice rapid fire inputs for Mario kart Wii. The current configuration is for a handheld legend adapter, in order to change that button mappings you will need to define a custom profile, there are instructions in the gamepad/CustomGamepadExample.py

Dependencies:
https://github.com/piborg/Gamepad (bundled in the program)
colorama, Use ```pip install colorama``` to install.
